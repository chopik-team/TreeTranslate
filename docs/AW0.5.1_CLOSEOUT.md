# AW 0.5.1-alpha — закрытие цикла

Дата: 21 сентября 2026.

Открытие папки готового результата и восстановление исходных путей незавершённой задачи работают; обе настройки по умолчанию выключены. Восстановление запускается при показе окна, без отложенного callback. Перевод после восстановления начинается заново по кнопке, а не с последнего сегмента. Завершённые и явно отменённые задачи очищаются; закрытие во время обработки сохраняет очередь. Удалена настройка масштаба интерфейса.

## Проверки

- Все 213 тестов прошли при запуске каждого `tests/test_*.py` отдельным процессом pytest.
- В том числе прошли реальные переводы текста и DOCX на CPU/GPU/Auto, native Windows GUI smoke и проверки отсутствия фоновой сети.
- `python -m compileall -q app` и `git diff --check` прошли.
- Известная нестабильность: единый процесс `pytest -q` иногда завершается с Windows access violation при обработке событий Qt между UI-тестами. Ранее полный прогон проходил, но при финальной проверке сбой повторился. Причина не установлена; раздельный прогон не считается исправлением этой проблемы.

## Передача следующему циклу

Исходники зафиксированы тегом `aw0.5.1-alpha`; следующий цикл подготовлен в ветке `codex/aw0.6-alpha`. Версия в приложении остаётся последней выпущенной до начала следующего этапа. Установщик и новый пакет моделей в этом цикле не собирались. Известную нестабильность общего Qt-прогона следует исследовать отдельно.
