# AW 0.7.7 — Language Support UX

28 сентября 2026. Небольшой UI/data patch поверх AW0.7.6. Внешний поиск, новые модели, языки и повторный языковой аудит не выполнялись.

## Реализация

В «О проекте» добавлена вкладка «Поддержка языков» между движками и лицензиями: семь карточек, флаги, готовность базового перевода, DOCX/native PDF, OCR, ресурсные счётчики и сворачиваемые подробности. EN/EN-US — один code=en. Selector не изменён. Тема и скруглённые карточки переиспользуют существующий стиль; области вкладок выделено растягиваемое место и минимальная высота 260 px. [Снимок интерфейса](language-support.png).

Capabilities — генерируемая проекция существующей `docs/qa/aw076/language-matrix.json`; описание маршрутизации — из `docs/LANGUAGE_SUPPORT.md`. Исторический аудит AW0.7.6 не изменён. Генератор `tools/build_language_support.py` считает строки SQLite в mode=ro и записывает `assets/language-support.json`. Widget не сканирует базы, не загружает модели и не обращается к сети.

Источники: technical knowledge `entries` по source_language; WordNet/OpenRussian `articles`; FreeDict `entries`; Tatoeba `examples`. Технические записи повторяются между областями и не называются уникальными словами. Формы, senses, example links, tokenizer/model vocabulary и пользовательские TM/glossary не суммируются. Нет ресурса = null / «Отдельная база не добавлена».

Глубина: 1 начальная звезда + OCR release support + техническая база + словарь любой из двух категорий + примеры. По одному баллу за семейство; максимум 5. Это не оценка качества перевода. Все семь кодов сохраняют RELEASE_READY; OCR заявлен только RU/EN/ZH, для остальных — «не заявлено» с пояснением про visual/script QA.

History находится в том же JSON: реальные технические counts AW0.7.4 и статьи/примеры AW0.7.5, с указанием версии и источника. Они не изменились. Для двуязычных записей previous=null — первый снимок. AW0.7.7 является первым общим снимком. При смене версии генератор сохраняет прежний снимок в history; при повторной сборке той же версии не дублирует его. Рост зелёный, уменьшение красное, unchanged нейтральный; previous серый. Все четыре состояния покрыты тестами.

## Изменённый интерфейс

- `app/gui/dialogs/about_dialog.py`: новая вкладка и растяжение области вкладок.
- `app/gui/widgets/language_support_tab.py`: модуль карточек и disclosure; отдельный класс оправдан объёмом вкладки, базовые Qt-компоненты и флаги переиспользованы.
- `app/gui/styles/stylesheet.qss`: новая карточка включена в существующее правило.
- `app/gui/dialogs/changelog_dialog.py`: запись о версии.

Read-only helper — `app/services/language_support.py`. Версия, README, CHANGELOG, NEXT_CYCLE и LANGUAGE_SUPPORT обновлены. Core Router, resolver, inference, OCR, документы и glossary pipeline не менялись.
