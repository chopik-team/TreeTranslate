# AW0.81 — оценка времени и обратный отсчёт

Исправлена остановка оставшегося времени после первоначальной оценки. Оценка появляется после добавления и проверки файлов, уменьшается каждую секунду во время обработки и уточняется по фактическому прогрессу. Пауза не расходует оставшееся время. При завершении показывается `00:00:00`.

## Данные для оценки

В `assets/config/document-performance.json` сохранены числовые данные принятого прогона `736fc7a72805`: 100 PDF за 1428,599 с, около **252 обработанных PDF/час**, 395,63 исходных страниц/час. Это скорость обработки всей выборки: 76 документов переведены, 24 завершились с сохранением исходника. Она не означает 252 успешно переведённых PDF/час для любого архива.

Для текстовых, смешанных и сканированных PDF сохранены отдельные затраты на сегмент, OCR и запись страницы. Профили рассчитаны по успешно переведённым документам; ошибочные документы не занижают стоимость успешного перевода. Замеры относятся к китайскому → русскому и текущей конфигурации с RTX 3080. Для явно выбранного CPU или другой языковой пары используется подходящая локальная история, когда она есть.

Также сохранены ссылки на диагностический прогон пяти сложных PDF `2bf4fd0f345e` и старый прогон до оптимизации `25825c3f75a7`. Они не подменяют текущую представительную скорость. Результаты отклонённого эксперимента NMT batching не используются.

Подключена существующая локальная история измерений. Смешанные маршруты GPU с CPU fallback теперь допускаются при выборе соответствующего устройства. Из подходящих завершённых запусков берутся последние восемь; прогоны с паузами и слишком короткие служебные запуски отфильтровываются.

## Поведение

- Отдельный PDF: недорогая проверка количества страниц, объёма текста и областей изображений, которым потребуется OCR. Для большого PDF исследуются первая, средняя и последняя страницы. Модели, OCR и семантический перевод для оценки не запускаются.
- Папка: первоначальный анализ ограничен первыми 16 документами; остальные получают приблизительный бюджет по размеру. При обработке оценка уточняется.
- ZIP: оценка использует уже готовый список членов и их размеры. Для расчёта не извлекаются и не открываются все PDF архива. Это приближение сложности, а не предварительный полный анализ содержимого.
- Запуск: оценка показывается до первого результата переводчика. Существующий таймер интерфейса обновляет её каждую секунду, включая длительное ожидание внутри модели.
- Пауза: отсчёт замораживается и продолжается после возобновления.
- Обработка: реальные сегменты и время работы уточняют оставшийся бюджет. Скорость одного документа не заменяет профиль сложности другого документа.
- Завершение: ноль; отмена или ошибка: прочерк. Если исходная оценка истекла, а работа продолжается, отображается «Оценка уточняется…», без ложного завершения.

При уточнении оценка может увеличиться, если фактическая работа тяжелее первоначального прогноза. Между уточнениями время отсчитывается вниз. Для коротких документов холодная загрузка модели может существенно влиять на погрешность.

## Проверки

Целевые проверки: добавление настоящего PDF через интерфейс → оценка сложности → запуск обработки с контролируемым переводчиком → уменьшение времени → пауза/возобновление → завершение и сохранение результата. Проверена неизменность исходного PDF.

Отдельно проверены ежесекундные обновления через очереди сигналов Qt, отсутствие зависания после превышения бюджета этапа, сохранение отдельных профилей сложности, fallback без калибровки и синтетический архив из 1000 членов без открытия PDF для оценки.

Смежные проверки охватывают обработку документов, интерфейс, ZIP и адаптивный конвейер. Итог: **116 passed**, 64,57 с. Команда: `python -X utf8 -m pytest tests/test_live_document_eta.py tests/test_document_measurements.py tests/test_document_service.py tests/test_ui_smoke.py tests/test_zip_output.py tests/test_adaptive_pipeline.py -q`.

Новые компоненты интерфейса не создавались: расширены существующие оценщик времени, сервис обработки, контроллер и панель прогресса. Качество перевода, Knowledge, NMT и дизайн интерфейса этим изменением не менялись. Полный CN7C не запускался.
