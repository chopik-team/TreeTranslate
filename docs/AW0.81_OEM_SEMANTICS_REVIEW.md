## Подтверждённые смыслы

- `turn_signal_lamp_assembly`: указатель поворота в сборе. Общий вариант `灯总成` применим только при явном указателе поворота в том же сегменте. Снятие патрона/лампы сохраняет их роли, последовательность и буквенные маркеры. Существующие INSTALL-шаблоны получили разрешение только для подтверждённого полного узла.
- `washer`: прежнее понятие шайбы сохранено; уплотнительное свойство не добавлено.
- `v_belt` / `engine_v_belt`: клиновой ремень / клиновой ремень двигателя. Это уточнение типа ремня, без глобальной замены на поликлиновой.
- `side_of_engine_block`: сбоку блока цилиндров; требуется контекст компрессора и хладагента в документе.
- `belt_rib_side`: ребристая сторона ремня; исходная неточная китайская формулировка нормализуется только при подтверждённом осмотре износа ремня. Условие отсутствия крупных участков рёбер ведёт к замене ремня. Старый reference не используется как источник нового правила.
- `engine_room_under_cover`: существующий concept `aw087:e3725f72dfd6ab1feac3` сохранён. `机舱被掩盖` — только вариант заголовка перекрёстной ссылки. Восстановление отсутствующих завершающих кавычек и скобки разрешено только для этого целиком известного, явно проверенного варианта; неизвестные и удлинённые названия сохраняются исходными.
- Два OEM пункта EVAP сохранены отдельно: «Проверка герметичности системы EVAP» и «Проверка утечек системы улавливания паров топлива». Они не относятся к испарителю кондиционера. EVAP, отсутствующий в локализованном китайском заголовке, может добавляться только точной проверенной словарной подписью; обычный валидатор по-прежнему отклоняет произвольное добавление идентификаторов.
- `gpf_service_regeneration`: сервисная регенерация GPF.
- D Pri / E Sec: первичный / вторичный. См³ наследуются только из заголовка ёмкости бачка в cc при наличии DOT4 в том же документе. Значения и допуски не записаны в правилах и не пересчитываются. Без такого заголовка либо при другой единице/букве правило не применяется. Исключение для ошибочного китайского «до» проверяется повторным вычислением точной подписи, без доверия к одному флагу результата.
