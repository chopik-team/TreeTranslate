# AW 0.8.4 — требования к оценке движка

Основание: AW 0.8.3 исправляет короткие термины и геометрию, но текущий M2M100 продолжает разрушать смысл отдельных инструкций. CURRENT MODEL LIMITATION: YES. Этот документ задаёт следующий эксперимент; интеграции и загрузки модели в AW 0.8.3 нет.

| Критерий | Требование к эксперименту |
|---|---|
| Режим | Полностью offline после явной подготовки ресурсов; ноль сетевых обращений при переводе. |
| Платформа | Windows, существующее Python/Qt-приложение; сначала отдельный QA runner без изменения production router. |
| Направления | Прямой ZH→RU обязателен, RU→ZH проверяется отдельно. Качество первого направления нельзя выдавать за готовность второго. |
| Лицензия | Проверить отдельно лицензию весов, токенизатора, runtime и право распространять модель с приложением. Зафиксировать ограничения, источник, revision, notices и SHA-256. |
| Размер | Записать размер скачивания, установленный размер, токенизатор, квантизацию и влияние на пакет/установщик. Не скрывать дополнительные ресурсы для pivot. |
| GPU | RTX 3080 12 GB: измерить реальный пиковый VRAM при загрузке, коротких подписях и длинной инструкции. Оставить запас для OCR и GUI; OOM считается провалом конфигурации. |
| CPU fallback | Тот же корпус без CUDA; измерить холодную загрузку, задержки, RAM, отмену и освобождение ресурсов. CPU не должен молча менять смысл перевода. |
| RAM/VRAM | Замеры процесса и дочерних workers до загрузки, на пике и после unload. Записать ограничения рабочей машины и минимальную пригодную конфигурацию. |
| Runtime | Проверить Windows wheels/DLL, совместимость CUDA, квантизацию, размер контекста, обработку длинных сегментов, потоковую отмену и безопасное завершение workers. |
| Установщик | Явный выбор/подготовка дополнительных компонентов; лицензии и контрольные суммы; отсутствие загрузки по умолчанию во время обычного перевода. |
| Knowledge | Сохранить TM, пользовательские приоритеты, BUILTIN exact bypass и ограничения. Сравнивать raw model и model+Knowledge отдельно. |
| Качество | Использовать `qa/aw083/body_dimensions_gold.json`; оценивать названия, технические подписи и целые инструкции. Не включать весь тестовый документ в production lookup. |
| Геометрия | Нулевые потери защищённых чисел, Ø, prime marks и идентификаторов. OCR labels по-прежнему не создают продолжения документа. |
| Скорость | Одинаковые профиль, устройство и вход; холодные и тёплые прогоны отдельно, без одновременного regression runner. Полный ZIP-прогон важнее суммы отдельных задержек. |
| Gate | Существенно улучшить ошибки смысла, а не только грамматику. Показать отдельные неудачи и затраты ресурсов; решение об интеграции — только после следующего задания. |

Не выбран и не рекомендован конкретный новый продукт или модель: сначала нужно сравнение кандидатов с проверкой их актуальных официальных лицензий и runtime. Не заменять M2M100 автоматически и не включать экспериментальный pivot в production.
