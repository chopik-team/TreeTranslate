# История изменений TreeTranslate

## AW 0.5.1-alpha — 21 сентября 2026

- «Открывать папку после завершения» открывает каталог готового результата; по умолчанию выключено.
- «Восстанавливать незавершённую задачу после запуска» сохраняет исходные пути локально и повторно сканирует их при показе окна; по умолчанию выключено. Перевод запускается пользователем заново, без восстановления позиции внутри документа.
- Завершённые и явно отменённые задачи удаляются из восстановления. Закрытие приложения во время перевода сохраняет задачу; отклонённый выбор файлов не подменяет её.
- Удалена неработающая настройка масштаба интерфейса.

## AW 0.5-alpha — 16 сентября 2026

Phase 1: настоящий перевод DOCX через существующий Hybrid Engine.

- Qt-free Document Layer: recursive scanner, логические блоки, определение языка документа, безопасная сборка и проверка DOCX.
- Абзацы, заголовки, списки, таблицы и колонтитулы переводятся между защищёнными границами; отдельные runs не отправляются в движок.
- Сохраняются стили, ссылки, изображения и встроенные объекты. Inline-выделение переносится приблизительно; поля и URL остаются без изменений.
- Реальный прогресс, Pause/Resume/Cancel, общий единственный worker и удержание модели на время задания/паузы.
- Публикация после проверки ZIP/python-docx и SHA256 оригинала; коллизии не перезаписываются. Custom output, вложенность и перевод каталогов работают.
- Добавлены независимые настройки перевода названий папок и файлов. Имя DOCX переводится тем же тёплым Router, расширение сохраняется, Windows-имена очищаются, а пустой или зарезервированный результат откатывается к исходному имени.
- Демонстрация заменена DOCX; другие форматы честно не поддерживаются. Добавлены путь результата и открытие файла/папки.
- python-docx 1.2.0 / lxml 6.0.2, unit/integration tests и реальный GUI smoke CPU/Auto/GPU.
- PDF/OCR/архивы, TM, Glossary и fine-tuning не входят в этот этап.

## AW 0.4-alpha — 15 сентября 2026

Phase 1: Hybrid Translation Engine для обычного текста. Перевод файлов остаётся демонстрацией.

### Словарь, подсказки и настройка режимов

- Демонстрационные примеры заменены локальным поиском FreeDict/WikDict EN↔RU: 104 781 статья, произношение, части речи и отдельные значения. Добавлен набор оригинальных учебных примеров с контекстом и вариантами перевода.
- Исправление орфографии и дополнение текущего слова работают в фоне: Enter/Tab принимают выбранный вариант, стрелки меняют выбор, Esc закрывает список, Shift+Enter вставляет новую строку. Русский, английский, немецкий, французский и испанский словари поставляются локально с pyspellchecker.
- Наведение на слово показывает пояснение; выделение открывает словарную статью. Для отдельного слова вариант можно вставить в перевод, для слова внутри предложения — скопировать. Поздний ответ движка не перезаписывает выбор.
- Соседние предложения теперь сохраняют общий контекст абзаца. Сокращения и ссылки местоимений больше не разрываются механически после каждой точки; длинные абзацы ограничены по токенам без скрытого усечения.
- В «Максимуме» EN↔RU использует специализированный Argos: проверка показала более точные формулировки на тестовых фразах. ZH↔RU сохраняет прямой маршрут M2M100 в допускающих его профилях.
- Потоки и глубина поиска проверены на 5700X/RTX 3080. Турбо использует beam=2, Баланс/Автоматический — 4, Максимум — 5; все, кроме Эконома, используют до 8 CPU-потоков по умолчанию. Явная настройка пользователя сохраняет приоритет.
- Убраны выдуманные скорости слов/мин и требования RAM в списке режимов.
- По запросу владельца убрано предупреждение об условиях Argos EN↔RU из «О проекте». Лицензионных блокировок или искусственного снижения производительности движка не было и нет.
- Runtime не скачивает словари, модели и дополнительные данные. Подготовка FreeDict вынесена в отдельный инструмент разработчика с проверкой официальных SHA512.

### Engine / offline architecture

- Исправлена диагностика локального runtime: единый `MODELS_DIR` разрешается от корня приложения независимо от cwd, а безопасный лог различает `model_root`, наличие manifest, состояние модели и отсутствующую runtime-зависимость без записи пользовательского текста.
- Добавлены нейтральные TranslationRequest / TranslationResult, capabilities, InferenceOptions, ошибки отсутствия/повреждения модели, устройства, неподдерживаемой пары и отмены.
- Сохранена цепочка GUI → controller → service → engine. Новый TextTranslationEngine Protocol описывает реальный текст; прежний file/job ABC AW 0.3 оставлен совместимым.
- ArgosBackend получает фактические пары через официальный Package API из локальной директории TreeTranslate. Direct и pivot различаются; глобальные пользовательские packages не используются.
- Для исключения PyTorch и скрытых SBD загрузок официальный Argos wheel используется через package/tokenizer API с небольшим CT2 адаптером. Upstream не форкался. Абзацы обрабатываются с ограничением длины токенов.
- M2M100 418M преобразована из официальных upstream весов в CTranslate2 INT8. Runtime использует локальный SentencePiece tokenizer; Transformers/PyTorch оставлены в отдельном build environment.
- ModelManager читает manifest, версии, размеры, SHA256 и состояния моделей. На старте нет хэширования больших файлов; полная проверка вынесена в ручной инструмент.
- Runtime использует только локальные артефакты. HF offline flags, отключённая телеметрия/debug, запрет Python socket/HTTP на engine thread, тесты без доступа к сети.

### Router / lifecycle / UI

- Нижние словарь и примеры показываются только для одного введённого или явно выделенного слова и сразу скрываются для фразы из двух и более слов. Подсказки исправления поддерживают до девяти вариантов: клавиши `1–9` выбирают вариант по номеру, `Enter` всегда принимает первый.
- В панель файлового перевода добавлена кнопка «Показать в папке»: после получения существующего выходного файла она открывает Проводник с выделенным результатом, а для нескольких результатов — папку сохранения. В демонстрационном файловом режиме кнопка не имитирует отсутствующий результат и остаётся неактивной.
- В «О проекте» добавлена краткая сводка локальных движков; технические сведения об артефактах сохранены в `THIRD_PARTY_NOTICES.md`.
- В переводческих списках разделены британский английский и английский США: «Английский» использует британский флаг, «Английский (США)» — американский; оба варианта совместимы с текущим кодом моделей `en`.
- На страницу перевода текста добавлен общий селектор режима Автоматический/Эконом/Быстрый/Баланс/Турбо/Максимум; профиль синхронизируется с файловой страницей, настройками и активным Hybrid Translation Engine.
- Статическая стрелка между языками заменена кнопкой обмена: исходный и целевой языки атомарно меняются местами и синхронизируются между обеими страницами и локальными настройками.
- Детерминированный Router: приоритет direct, M2M100 для ZH↔RU в Balanced/Automatic/Maximum, явная цепочка разрешённых fallback.
- CPU/GPU/Auto реально передаются в CTranslate2. Явный GPU не превращается в CPU; Auto допускает fallback на CPU. Compute type выбирается по capabilities.
- Economy/Fast/Balanced/Turbo/Maximum/Automatic вынесены в JSON; параметры уточнены реальными замерами, потоки, beam size, размеры пакетов и idle timeout централизованы.
- Lazy loading: запуск GUI не импортирует модели, SentencePiece или CUDA. Backend остаётся тёплым между запросами и выгружается после 180 секунд простоя; shutdown освобождает модели.
- Inference выполняется в одном worker; один ожидающий запрос заменяется актуальным. Результаты устаревших запросов и запросов с изменённым языком/устройством отбрасываются.
- Сохранён max_active_translation_jobs=1. Отмена текста сохраняет занятость сессии до фактического окончания native inference.
- Исправлено аварийное завершение Windows после GPU-перевода: CUDA-ресурсы освобождаются на worker до его остановки. Реальный Qt smoke проверяет GPU idle/reload и код выхода процесса.
- Сохранены общая компоновка и визуальный стиль; по новому запросу восстановлены реальные словарные панели и подсказки ввода. Idle unload и неподключённые resource limits обозначены в настройках.

### Development / verification

- Добавлен `run_dev.bat` для быстрого запуска TreeTranslate из корня проекта строго через подготовленную `.venv`, независимо от текущего каталога оболочки; отсутствие окружения и аварийный код завершаются понятным сообщением.
- Инструменты подготовки моделей с явным `--allow-network`, проверки SHA256 и сравнения runtime tokenizer с официальным.
- Бинарники моделей, build sources и виртуальные окружения исключены из Git. Metadata, licenses и manifest версионируются.
- Добавлены unit, service, offline, lifecycle и real-model integration tests. Старые UI tests используют явно внедрённый mock.
- Benchmark измеряет cold/warm latency, chars/sec, whitespace words/sec, RSS и GPU memory snapshots. Каждый сценарий выполняется в новом процессе, перевод не кэшируется.
- Реальные результаты Ryzen 7 5700X / RTX 3080 12 GB сохранены в `docs/benchmarks`. Профили пока не перекалиброваны; оценок качества не заявлено.
- THIRD_PARTY_NOTICES фиксирует проверенные версии и неопределённость лицензий весов Argos EN↔RU.

PDF, DOCX, OCR, ZIP/RAR processing, реальное дерево файлов, Translation Memory, Glossary и восстановление файловых задач не добавлялись.

## AW 0.3-alpha — 15 сентября 2026

Цикл UI / Architecture завершён. Интерфейс и базовая архитектура приняты как Freeze Candidate для начала отдельной разработки AW 0.4 Hybrid Translation Engine. Настоящий Translation Engine в этой версии намеренно отсутствует.

### Изменения

- Исправлена регрессия индикаторов ускорения после централизации темы: Qt снова корректно отображает выбранные и невыбранные состояния Auto/CPU/GPU через переносимые runtime-пути SVG.
- Завершён третий этап и финальный аудит UI/architecture polish: проект переведён в состояние UI Freeze Candidate перед проектированием Translation Engine.
- Повторяющиеся локальные стили виджетов перенесены в общий QSS; все цвета интерфейса и кастомной отрисовки теперь берутся из централизованных theme tokens.
- Drag-and-drop, бейдж дерева, стрелка языков, процент прогресса, меню бренда, переключатель и splitter больше не содержат собственных захардкоженных палитр.
- Добавлен локальный ротационный logging с уровнями DEBUG/INFO/WARNING/ERROR в каталоге данных приложения; содержимое пользовательских документов не журналируется и логи никуда не отправляются.
- Расширена нейтральная граница будущего движка: добавлены capabilities и status без привязки к CUDA, ROCm, модели или конкретному backend.
- Проверены структура модулей, startup, idle-таймеры, assets, dead code, дубликаты, сетевые обращения и явное разделение mock/placeholder-компонентов.
- Завершён второй этап UI-полировки: Auto/CPU/GPU, профиль производительности, языки и перевод каталогов используют единое живое состояние на обеих страницах и в настройках.
- Добавлен централизованный координатор сеансов с текущим лимитом в одну активную задачу и подтверждением перед остановкой перевода при смене раздела.
- Автоперевод текста использует debounce 420 мс, идентификаторы запросов и игнорирование устаревших результатов без блокировки GUI-потока.
- Полная машина состояний включает IDLE, SCANNING, READY, TRANSLATING, PAUSED, CANCELLING, CANCELLED, COMPLETED и ERROR.
- Предварительные скорости режимов отделены в модели представления и готовы к замене данными будущего benchmark без переделки UI.
- Завершён первый этап автономизации: ресурсы TreeTranslate отвязаны от внешней структуры, а QSS-пути формируются переносимо из единого `paths.py`.
- Добавлены централизованные токены темы и `ThemeManager`; выбранная тёмная или системная тема сохраняется локально и восстанавливается при запуске.
- Настройки языков, режима, CPU/GPU, переключателей и папки результата сведены к единому `SettingsService` и синхронизированы с главным окном.
- Пользовательская папка результата восстанавливается точным путём и изменяется отдельной кнопкой «Изменить…».
- Защита оригиналов закреплена как неизменяемое правило: переключатель удалён, исходные файлы всегда сохраняются.
- Определение оборудования нормализует названия CPU/GPU, показывает достоверные RAM/VRAM и сохраняет профиль локально; рекомендации оставляют резерв памяти операционной системе.
- Название TreeTranslate в окне «О проекте» стало ссылкой на репозиторий продукта и подсвечивается фирменным зелёным при наведении.
- Подготовлен концептуальный roadmap AW 0.4: Translation Router, Argos Backend, M2M100 418M INT8 Backend, Translation Memory, Glossary и Cache; OCR/PDF/DOCX и ML-зависимости не добавлялись.

## AW 0.2-alpha — 14 сентября 2026

Первый расширенный альфа-релиз после UI-прототипа AW 0.1.

- Временные флаги Китая и Японии заменены PNG-иконками пользователя во всех селекторах; китайский и японский добавлены во вкладку языка интерфейса.

## AW 0.1 — первый UI-релиз

### Интерфейс и UX

- Реализованы страницы перевода файлов и текста.
- Добавлены drag-and-drop, дерево файлов, параметры языков и производительности.
- Перевод текста переведён в автоматический mock-режим.
- Добавлены словарь, связанные слова и примеры использования.
- Реализованы настройки, меню логотипа, окно «О проекте» и фирменная тёмная тема.

### Архитектура

- GUI, контроллеры, сервисы и модели разделены на независимые модули.
- Добавлен неблокирующий mock-сервис на QTimer.
